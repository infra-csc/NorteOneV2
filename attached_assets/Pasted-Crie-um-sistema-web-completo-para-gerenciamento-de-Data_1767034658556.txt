Crie um sistema web completo para gerenciamento de Data Warehouse financeiro de uma empresa de eventos. O sistema será a "fonte única de verdade" (Single Source of Truth) para dados orçamentários, projeções e realizados.

## Stack Tecnológica

- **Backend:** Python com FastAPI
- **Frontend:** React com TypeScript e Tailwind CSS
- **Banco de Dados:** PostgreSQL
- **ORM:** SQLAlchemy
- **Autenticação:** JWT
- **Gráficos:** Recharts ou Chart.js

## Modelo de Dados

### Tabelas Dimensionais

```sql
-- Dimensão Tempo
CREATE TABLE DIM_TEMPO (
    id SERIAL PRIMARY KEY,
    data DATE UNIQUE NOT NULL,
    dia INT,
    mes INT,
    trimestre INT,
    semestre INT,
    ano INT,
    dia_semana VARCHAR(20),
    nome_mes VARCHAR(20),
    is_feriado BOOLEAN DEFAULT FALSE
);

-- Dimensão Centro de Custo
CREATE TABLE DIM_CENTRO_CUSTO (
    id SERIAL PRIMARY KEY,
    codigo VARCHAR(20) UNIQUE NOT NULL,
    nome VARCHAR(100) NOT NULL,
    area VARCHAR(50),
    gestor_responsavel VARCHAR(100),
    ativo BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP
);

-- Dimensão Conta Contábil
CREATE TABLE DIM_CONTA (
    id SERIAL PRIMARY KEY,
    codigo VARCHAR(20) UNIQUE NOT NULL,
    nome VARCHAR(100) NOT NULL,
    tipo VARCHAR(20) CHECK (tipo IN ('RECEITA', 'DESPESA')),
    grupo VARCHAR(50),
    subgrupo VARCHAR(50),
    ativo BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT NOW()
);

-- Dimensão Projeto/Evento
CREATE TABLE DIM_PROJETO (
    id SERIAL PRIMARY KEY,
    codigo VARCHAR(20) UNIQUE NOT NULL,
    produto VARCHAR(50) NOT NULL,
    modalidade VARCHAR(20) CHECK (modalidade IN ('BEACH', 'CICLISMO', 'CORRIDA', 'CULTURA', 'EDUCACAO' ,'E-SPORTS', 'FAMILIA', 'NATACAO', 'OBSTACULO', 'SAUDE', 'TRIATHLON')) NOT NULL,
    tipo_evento VARCHAR(50) CHECK (tipo_evento IN ('PROPRIO', 'INCENTIVO', 'ORGANIZACAO', 'LICENCIADO')) NOT NULL,
    evento VARCHAR(200) NOT NULL,
    lei VARCHAR(50) CHECK (lei IN ('LIE', 'PIE', 'FIA', 'ICMS RJ','PROAC', 'PRONAC', 'ROUANET', 'ISS RJ')) NOT NULL,
    cliente VARCHAR(100),
    status VARCHAR(20) CHECK (status IN ('EM_ANDAMENTO', 'CONCLUIDO', 'CANCELADO')) NOT NULL,
    data_evento DATE NOT NULL,
    local_evento VARCHAR(150) NOT NULL,
    cidade VARCHAR(100),
    estado VARCHAR(50),
    capacidade_maxima INT,
    etapa INT,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP
);

-- Dimensão Categoria de Atleta (NOVO)
CREATE TABLE dim_categoria_atleta (
    id SERIAL PRIMARY KEY,
    codigo VARCHAR(20) UNIQUE NOT NULL,
    nome VARCHAR(100) NOT NULL,
    faixa_etaria VARCHAR(50),
    genero VARCHAR(20) CHECK (genero IN ('MASCULINO', 'FEMININO', 'MISTO')),
    modalidade VARCHAR(50),
    is_pcd BOOLEAN DEFAULT FALSE,
    valor_inscricao_padrao DECIMAL(10,2),
    custo_kit_padrao DECIMAL(10,2),
    ativo BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT NOW()
);

-- Dimensão Usuário
CREATE TABLE DIM_USUARIO (
    id SERIAL PRIMARY KEY,
    email VARCHAR(100) UNIQUE NOT NULL,
    nome VARCHAR(100) NOT NULL,
    senha_hash VARCHAR(255) NOT NULL,
    perfil VARCHAR(20) CHECK (perfil IN ('ADMIN', 'GESTOR', 'ANALISTA', 'VISUALIZADOR')),
    centro_custo_id INT REFERENCES DIM_CENTRO_CUSTO(id),
    ativo BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT NOW()
);
```

```sql
-- View consolidada de atletas com métricas calculadas
CREATE VIEW vw_atletas_consolidado AS
SELECT 
    fa.id,
    p.codigo as projeto_codigo,
    p.nome as projeto_nome,
    p.tipo_evento,
    ca.codigo as categoria_codigo,
    ca.nome as categoria_nome,
    ca.modalidade,
    ca.faixa_etaria,
    ca.genero,
    t.data,
    t.mes,
    t.ano,
    fa.qtd_atletas_orcado,
    fa.qtd_atletas_projetado,
    fa.qtd_atletas_realizado,
    fa.valor_inscricao_unitario,
    fa.custo_kit_unitario,
    -- Métricas calculadas
    (fa.qtd_atletas_orcado * fa.valor_inscricao_unitario) as receita_orcada,
    (fa.qtd_atletas_projetado * fa.valor_inscricao_unitario) as receita_projetada,
    (fa.qtd_atletas_realizado * fa.valor_inscricao_unitario) as receita_realizada,
    (fa.qtd_atletas_orcado * fa.custo_kit_unitario) as custo_kit_orcado,
    (fa.qtd_atletas_realizado * fa.custo_kit_unitario) as custo_kit_realizado,
    CASE WHEN fa.qtd_atletas_orcado > 0 
        THEN ROUND(((fa.qtd_atletas_realizado - fa.qtd_atletas_orcado)::DECIMAL / fa.qtd_atletas_orcado) * 100, 2)
        ELSE 0 
    END as variacao_orc_real_pct,
    CASE WHEN fa.qtd_atletas_projetado > 0 
        THEN ROUND(((fa.qtd_atletas_realizado - fa.qtd_atletas_projetado)::DECIMAL / fa.qtd_atletas_projetado) * 100, 2)
        ELSE 0 
    END as variacao_proj_real_pct
FROM fato_atletas fa
JOIN dim_projeto p ON fa.projeto_id = p.id
JOIN dim_categoria_atleta ca ON fa.categoria_atleta_id = ca.id
LEFT JOIN dim_tempo t ON fa.tempo_id = t.id;
```

## Módulos e Funcionalidades

### 1. Autenticação e Autorização
- Login com email/senha
- JWT para sessões
- Perfis de acesso: ADMIN (tudo), GESTOR (seu centro de custo), ANALISTA (cadastros), VISUALIZADOR (apenas consulta)
- Tela de gerenciamento de usuários (apenas ADMIN)

### 2. Cadastros (Dimensões)
Telas CRUD completas para:
- Centro de Custo (com campo de gestor responsável)
- Contas Contábeis (com tipo receita/despesa e hierarquia grupo/subgrupo)
- Projetos/Eventos (com status, cliente, datas)
- Categorias de Atletas (modalidade, faixa etária, gênero, PCD, valores padrão)
- Usuários (apenas ADMIN)

### 3. Módulo Orçamento (Fase 1 - Base Referencial)
- Upload de planilha Excel/CSV para carga em massa
- Tela de entrada manual de orçamento por mês
- Visualização do orçamento anual/mensal por centro de custo
- Visualização do orçamento anual/mensal por projeto
- Versionamento do orçamento (V1, V2, etc.)
- Exportação para Excel

### 4. Módulo Projeções (Fase 2)
- Cada gestor vê apenas seu centro de custo
- Entrada de projeção mensal com justificativa
- Comparativo Orçado x Projetado
- Histórico de versões das projeções
- Workflow simples: Rascunho → Submetido → Aprovado/Rejeitado
- Indicador visual de variação (verde se menor, vermelho se maior que orçado)

### 5. Módulo Realizado (Fase 3)
- Upload de arquivo com lançamentos realizados
- Entrada manual de valores realizados
- Dashboard de acompanhamento com:
  - Orçado x Realizado (valores e %)
  - Orçado x Projetado x Realizado
  - Gráfico de evolução mensal
- Alertas visuais para desvios > 10%
- Drill-down por centro de custo, conta, projeto

### 6. Módulo Atletas (NOVO - Controle de Participantes)
Tela dedicada para gestão de atletas por evento:

**6.1 Cadastro de Categorias de Atletas**
- CRUD de categorias com: código, nome, faixa etária, gênero, modalidade, PCD
- Valor padrão de inscrição e custo de kit por categoria
- Exemplos de categorias: "Corrida 5K - Masculino Adulto", "Natação - Feminino Sub-17", "Ciclismo - PCD"

**6.2 Planejamento de Atletas por Evento**
- Selecionar evento e adicionar categorias participantes
- Informar quantidade orçada de atletas por categoria
- Definir valor de inscrição e custo de kit (pode herdar do padrão da categoria)
- Calcular automaticamente receita orçada e custo de kits

**6.3 Projeção de Atletas**
- Gestor revisa as quantidades orçadas
- Informa quantidade projetada com justificativa
- Histórico de versões da projeção
- Comparativo visual Orçado x Projetado

**6.4 Realizado de Atletas**
- Entrada da quantidade real de inscritos/participantes
- Upload de lista de atletas (opcional, para reconciliação)
- Atualização automática ou manual
- Comparativo Orçado x Projetado x Realizado

**6.5 Dashboard de Atletas**
Cards principais:
- Total de Atletas Orçados (ano/evento)
- Total de Atletas Projetados
- Total de Atletas Realizados
- Variação % Orçado x Realizado
- Receita Total (inscrições)
- Custo Total (kits)

Gráficos:
- Barras: Orçado x Projetado x Realizado por evento
- Pizza: Distribuição por modalidade
- Pizza: Distribuição por faixa etária
- Linha: Evolução de inscrições por mês
- Tabela: Ranking de eventos por número de atletas

Filtros:
- Ano, Mês, Evento, Modalidade, Categoria, Faixa Etária

### 7. Dashboard Consolidado (Fase 4)
- Visão executiva com cards de resumo:
  - Total Orçado (ano)
  - Total Projetado (ano)
  - Total Realizado (YTD)
  - Total de Atletas (ano) 
  - Variação Orçado x Realizado (%)
  - Receita por Atleta (média)  
- Gráfico de barras: Orçado x Projetado x Realizado por mês
- Gráfico de barras: Atletas por evento
- Gráfico de pizza: Distribuição por tipo (Receita x Despesa)
- Gráfico de pizza: Atletas por modalidade
- Ranking de maiores variações
- Filtros por: Ano, Mês, Centro de Custo, Projeto, Modalidade
- Exportação de relatório em PDF

### 8. Relatórios
- Relatório mensal por centro de custo
- Relatório por projeto/evento (custos e atletas)
- Relatório de atletas por categoria
- Relatório de variações (desvios)
- Relatório de receita de inscrições
- Todos exportáveis para Excel e PDF
